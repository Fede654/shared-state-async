shared by all three arms.

`sync` performed by a cold observer over the same shaped link:
a real full-state transfer, not bytes over nominal rate. It
includes merge time (the receiver's clock runs during merge, so
that is part of the divergence) and process startup (reported
per-run as `cli_overhead_s` so it can be subtracted).
